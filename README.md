# Zachary Baker - Tread Carefully!

### What I have:

2D puzzle game that is displayed rendered onto a 3D cube.

Puzzle mechanics:

-A player who moves and only has so many remaining steps before the level resets.

-Numbered Spots (1-9) which set the player's steps.

-Boxes which can be pushed by the player.

-Holes which are impassable until a box is pushed into them.

-Victory flags.

-Two complete levels. 
(The first demonstrates the depth of the numbered spots & limited steps mechanics.)
(The second showcases pushing boxes into holes, and the kind of difficult puzzles that can be created by combining that with the limited amount of steps.)

-You can push boxes to move victory flags and numbered spots. This would allow for much more creative puzzles.

=A moody room with flickering lights meant to evoke playing games as a kid when your parents are asleep. 

-A TV that the game is rendered unto, and has a moody pulsing light

-Ambient audio

-TV game audio

-All sprites made by me

### Systems:

A grid based system with objects that adhere to the grid

A main menu, 

a win screen,

A level loading system that can load different tilemaps, unload game objects, load game objects, reset the level.

Levels as assets for flexible level design,

An audio system

### Tutorial:
WASD to move. Reach the flag to win the level! 
Numbered spaces will change your remaining moves, use them wisely.
